# MBSD.Analysers.RedundantCode

A Roslyn analyzer that detects redundant code patterns across your C# solution.

## Features
- Identifies redundant code constructs
- Provides code fix suggestions (if implemented)
- Integrates with Visual Studio and other Roslyn-compatible IDEs

## Getting Started
1. Install the NuGet package:
   ```shell
   dotnet add package MBSD.Analysers.RedundantCode
   ```
2. Build your project. The analyzer will automatically run and report diagnostics in your IDE or build output.

## Usage
No additional configuration is required. The analyzer should just work after installation.
